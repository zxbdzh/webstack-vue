## About

webstack-vue is a bookmark management and web-navigation system built on the Vue 3 ecosystem: bookmark collection, category management, a user system and a full admin console. The frontend uses a modern stack; the backend is a separate API service ([webstack-backend](https://github.com/zxbdzh/webstack-backend)). Suitable for personal cloud bookmarks or a team navigation hub.

### ✨ Core features

- 🌟 Modern UI — Vue 3 + Element Plus
- 📱 Responsive layout — desktop / tablet / mobile
- 🌙 Theme switch — light / dark in one click
- 🔖 Bookmark import & export — Chrome / Edge / Firefox / 360
- 📂 Multi-level categories — parent-child organization
- 🛠️ Full admin console — tags, categories, users, bookmarks
- 👥 User system — register, login, password change, role separation
- 📖 Onboarding — first-run guide powered by Driver.js
